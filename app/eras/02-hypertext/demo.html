Current Projects

RiverText

A hypertext editor for the lab's workstations. You write a document and make links by selecting words and pointing at another document. It writes HTML so you never have to type tags.

Networked Library Catalogue

An experiment to put the library card catalogue on the Web, using the new <ISINDEX> search tag.

About the Lab

The Riverside Computing Lab is a small research group working on networked information systems. We are four researchers, two students and one very old laser printer.

The World-Wide Web

The World-Wide Web (W3) is a wide-area hypermedia information retrieval initiative aiming to give universal access to a large universe of documents. Everything is a document, every document has an address (a URL), and any document can link to any other.

Getting a browser

Line mode
Works on any terminal. Links are numbered; type the number to follow one.
X Window and Macintosh
Graphical browsers show links underlined in blue, and can display inline images.
